# Student Management System

A simple Student Management System built using Python.

## Features

- Add Student
- View Students
- Search Student
- Delete Student
- Exit Program

## Technologies Used

- Python 3

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python student_management.py
```

## Sample Output

```
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit
```
